# Compassion Hub - NGO Website

A premium, fully responsive non-governmental organization website built with PHP, HTML5, Vanilla CSS, and JavaScript.

## 🚀 Getting Started

### Prerequisites
- PHP 7.4 or higher
- A local server environment like XAMPP, WAMP, or Laragon.

### Installation
1. Clone or download this repository into your local server's root directory (e.g., `htdocs` for XAMPP).
2. Open your browser and navigate to `http://localhost/NGO` (or the folder name you chose).

## 📁 Project Structure
- `/assets`: Contains CSS, JS, and image assets.
  - `css/style.css`: Main stylesheet with design system and modern aesthetics.
  - `js/main.js`: Core JavaScript for navigation and interactivity.
- `/includes`: Reusable layout components.
  - `header.php`: Global navigation and metadata.
  - `footer.php`: Global footer with newsletter and contact info.
- `index.php`: Landing page with hero, mission, and impact stats.
- `about.php`: NGO story, vision/mission, and registration details.
- `programs.php`: Detailed information on core initiatives.
- `donate.php`: Supporting pages for online and offline donations.
- `volunteer.php`: Registration form for new volunteers.
- `blog.php`: News, success stories, and awareness articles.
- `gallery.php`: Visual representation of NGO impact.
- `contact.php`: Contact form and location details.

## ✨ Features
- **Premium Aesthetics**: Glassmorphism navigation, soft color palette, and modern typography.
- **Mobile Responsive**: Fully optimized for all screen sizes.
- **Impact Trackers**: Visual progress bars and counters for transparency.
- **Donation Ready**: Structured for online payments and direct bank transfers.
- **SEO Optimized**: Semantic HTML and descriptive metadata.
