# NGO Website Implementation Plan

Building a modern, premium NGO website based on the provided requirements.

## 🎨 Design System
- **Colors**: Primary (Soft Green/Blue), Secondary (White/Light Gray), Accent (Warm Orange for "Donate Now").
- **Typography**: Modern sans-serif (Inter/Outfit).
- **Aesthetics**: Glassmorphism, smooth scroll, micro-animations, high-quality emotional imagery.

## 🏗️ Architecture (PHP + Vanilla CSS + JS)
- `index.php`: Landing page with hero, mission, impact stats, and CTA.
- `about.php`: Story, mission, team.
- `programs.php`: Detailed project cards.
- `donate.php`: Payment options and transparency details.
- `volunteer.php`: Registration form.
- `gallery.php`: Masonry layout for photos/videos.
- `blog.php`: News and success stories.
- `contact.php`: Form, map, and contact info.
- `assets/css/style.css`: Main stylesheet.
- `assets/js/main.js`: Interactive elements.
- `includes/`: Header, footer, and common components.
